**Código Vigía** es una plataforma web sin fines de lucro destinada a la documentación, análisis, preservación histórica y retro-emulación de software clásico y descatalogado (abandoneware), enfocado principalmente en la saga **Pro Evolution Soccer (PES)** y herramientas de soporte esenciales.

🌐 **Visita la página web oficial:** [https://luisflash22.github.io/saga-pes/](https://luisflash22.github.io/saga-pes/)

---

## 🎮 Contenido del Archivo Histórico

El repositorio y la web organizan los archivos de resguardo verificados bajo estrictos estándares de seguridad:

### ⚽ Biblioteca de Juegos
* **Pro Evolution Soccer 5** — Incluye relatos en español de España. *(Sin contraseña)*
* **Pro Evolution Soccer 6** — Incluye relatos en español de España. *(Sin contraseña)*
* **Pro Evolution Soccer 2012** — Relatos en español latino + paquete opcional de España.
* **Pro Evolution Soccer 2013** — Relatos en español latino + paquete opcional de España.
* **Pro Evolution Soccer 2017** — Versión multilenguaje (vía Torrent) con librerías gráficas necesarias incluidas.

### 🛠️ Herramientas de Soporte y Optimización
* **Verificador de Integridad (SHA-256):** Utilidad para confirmar que los archivos descargados no estén corruptos.
* **PeaZip:** Descompresor de archivos de código abierto (`.7z`, `.rar`).
* **Free Download Manager (FDM):** Acelerador y gestor de descargas.
* **qBittorrent:** Cliente P2P libre de publicidad para archivos Torrent.
* **Kaspersky Free Antivirus:** Solución de seguridad recomendada para escanear los archivos de resguardo.

---

## 🔐 Seguridad e Integridad (SHA-256)

Para garantizar la seguridad de la comunidad, todos los archivos alojados en servidores de resguardo cuentan con un análisis previo de **Kaspersky** y disponen de códigos de verificación **SHA-256** dentro de la plataforma web para asegurar descargas limpias y sin modificaciones maliciosas.
